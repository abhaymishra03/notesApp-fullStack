# Notes App

A full-stack Notes application built using the **MERN stack**, allowing users to create, view, update, and delete notes through a RESTful API.

### Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **API Communication:** Axios

### Features

* Create and store notes in MongoDB
* Fetch and display notes dynamically
* Update existing notes using PATCH requests
* Delete individual notes
* RESTful API architecture for CRUD operations
* React state management for synchronizing UI with backend data
* Component-based frontend structure
